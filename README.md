# Focus Tomato

A simple focus timer for Android (Flutter). No account, no ads, no internet permission.

- App: `focus_tomato/` (`flutter test`, `flutter build appbundle --release`)
- Privacy policy: https://raysanthosh.github.io/focus-tomato/docs/ (source in `docs/`)
- Play Store steps: `PLAY_STORE_GUIDE.md`
- Release signing key is NOT in this repo (`keys/` and `android/key.properties` are git-ignored).
